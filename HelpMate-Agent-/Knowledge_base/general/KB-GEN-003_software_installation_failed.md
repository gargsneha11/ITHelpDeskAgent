# Software Installation Failed

Document ID: KB-GEN-003
Title: Software Installation Failed
Category: General > Software
Priority: Medium
Version: 1.0
Status: Active
Owner: IT Service Desk
Last Updated: 2026-09-15

## Symptoms

- Approved software fails to install.
- Installation stops with an error.
- Application installs but cannot start.
- Installation repeatedly fails on the same device.

## Possible Causes

1. Insufficient permissions.
2. Device does not meet software requirements.
3. Insufficient disk space.
4. Previous installation is incomplete.
5. Required system update is missing.
6. Software package is unavailable or corrupted.

## Prerequisites

- Software must be approved by the organization.
- User must have a supported device.
- Installation should be performed through the organization's approved software distribution method.

## Troubleshooting Steps

1. Confirm the software is approved by the organization.
2. Check device compatibility requirements.
3. Check available disk space.
4. Restart the device.
5. Retry the installation through the approved software distribution method.
6. Record the installation error if it fails again.
7. Check whether the software is available to other users.

## Resolution

The approved application installs and launches successfully.

## Escalation

Escalate to Software/Desktop Support if:

- Installation continues to fail.
- Administrative privileges are required.
- The software package appears corrupted.
- Multiple users experience the same installation failure.

## Security Notes

- Do not download software from unapproved sources.
- Do not bypass organizational security controls.
- Do not provide users with unauthorized administrator credentials.
