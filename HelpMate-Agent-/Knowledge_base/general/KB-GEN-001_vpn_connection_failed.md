# VPN Connection Fails

Document ID: KB-GEN-001
Title: VPN Connection Fails
Category: General > Remote Access
Priority: High
Version: 1.0
Status: Active
Owner: IT Service Desk
Last Updated: 2026-09-15

## Symptoms

- VPN client opens but cannot establish a connection.
- User receives an authentication or connection error.
- User cannot access internal resources while working remotely.
- VPN connection repeatedly disconnects.

## Possible Causes

1. No internet connectivity.
2. Incorrect account credentials.
3. Account is locked or inactive.
4. VPN access is not enabled.
5. VPN client is not running correctly.
6. VPN service may be unavailable.

## Prerequisites

- User must have a working internet connection.
- User must be authorized for organizational VPN access.
- Support staff should have access to approved account and VPN diagnostic tools.

## Troubleshooting Steps

1. Confirm the device has internet access.
2. Check the user's account status.
3. Verify that the user is authorized for VPN access.
4. Restart the VPN client.
5. Retry the VPN connection.
6. Check whether other users are experiencing the same issue.
7. If available, check the VPN service status.

## Resolution

The VPN connection is successfully established and internal resources are accessible.

## Escalation

Escalate to Network Support if:

- VPN access is disabled.
- Multiple users cannot connect.
- The VPN service appears unavailable.
- The issue persists after account and device checks.

## Security Notes

- Never request the user's password or VPN credentials.
- Do not disable security controls to establish a VPN connection.
