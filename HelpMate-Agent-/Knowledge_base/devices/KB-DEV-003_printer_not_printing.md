# Printer Is Not Printing

Document ID: KB-DEV-003
Title: Printer Is Not Printing
Category: Devices > Printer
Priority: Low
Version: 1.0
Status: Active
Owner: IT Service Desk
Last Updated: 2026-09-15

## Symptoms

- Print job remains in the queue.
- Printer does not respond.
- Document appears to print but no page is produced.
- Printer is shown as offline.

## Possible Causes

1. Printer is offline.
2. Print queue is stuck.
3. Incorrect printer selected.
4. Printer has no paper or toner.
5. Network connectivity issue.
6. Printer service is temporarily unavailable.

## Prerequisites

- User must have access to the approved organizational printer.
- Support staff should know the printer's asset name or location.

## Troubleshooting Steps

1. Confirm the correct printer is selected.
2. Check whether the printer is online.
3. Check paper and toner status.
4. Review the user's print queue.
5. Cancel any stuck print jobs.
6. Send a test document.
7. Check whether other users can print to the same printer.

## Resolution

The test document prints successfully.

## Escalation

Escalate to Desktop Support if:

- The printer remains unavailable.
- Multiple users cannot print.
- Hardware failure is suspected.
- The printer requires physical maintenance.

## Security Notes

Do not expose documents containing confidential information while troubleshooting.
