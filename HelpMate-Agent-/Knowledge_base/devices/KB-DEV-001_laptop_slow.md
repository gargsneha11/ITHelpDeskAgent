# Laptop Performance Is Slow

Document ID: KB-DEV-001
Title: Laptop Performance Is Slow
Category: Devices > Laptop
Priority: Medium
Version: 1.0
Status: Active
Owner: IT Service Desk
Last Updated: 2026-09-15

## Symptoms

- Applications take a long time to open.
- System responds slowly.
- Laptop becomes slow after running for an extended period.
- Applications may freeze or become unresponsive.

## Possible Causes

1. Too many applications running.
2. High CPU or memory usage.
3. Low available disk space.
4. Background updates or security scans.
5. Device has been running for an extended period.

## Prerequisites

- User should save any unsaved work before restarting.
- Support staff should have access to approved device diagnostic tools.

## Troubleshooting Steps

1. Ask the user to save their work.
2. Restart the laptop.
3. Check available disk space.
4. Close unnecessary applications.
5. Check whether system updates are running.
6. Check CPU and memory usage.
7. Retry the affected application.

## Resolution

Laptop performance returns to an acceptable level and applications operate normally.

## Escalation

Escalate to Desktop Support if:

- The device remains slow after troubleshooting.
- Hardware errors are detected.
- The device repeatedly freezes or crashes.

## Security Notes

Do not disable endpoint security software to improve performance.
