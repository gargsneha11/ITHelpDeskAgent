# Laptop Cannot Connect to Wi-Fi

Document ID: KB-DEV-002
Title: Laptop Cannot Connect to Wi-Fi
Category: Devices > Network Connectivity
Priority: Medium
Version: 1.0
Status: Active
Owner: IT Service Desk
Last Updated: 2026-09-15

## Symptoms

- Wireless network is not visible.
- Device cannot connect to the organization's Wi-Fi.
- Wi-Fi repeatedly disconnects.
- Device shows limited or no network connectivity.

## Possible Causes

1. Wi-Fi is disabled.
2. Incorrect network selected.
3. Wireless adapter issue.
4. Weak wireless signal.
5. Network authentication failure.
6. Temporary network outage.

## Prerequisites

- Confirm the user is in an area where the organization's Wi-Fi should be available.
- Support staff should have access to approved network diagnostic tools.

## Troubleshooting Steps

1. Confirm Wi-Fi is enabled.
2. Verify the correct organizational network is selected.
3. Move closer to an approved access point if possible.
4. Disconnect and reconnect to the network.
5. Restart the wireless adapter.
6. Restart the device.
7. Check whether other users are experiencing the same issue.

## Resolution

The device successfully connects to the organization's Wi-Fi and maintains a stable connection.

## Escalation

Escalate to Network Support if:

- Multiple users are affected.
- The device repeatedly fails authentication.
- The wireless adapter appears to be malfunctioning.
- An organizational network outage is suspected.

## Security Notes

Do not connect the user to unknown or unauthorized wireless networks.
