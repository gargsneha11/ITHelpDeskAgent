# Application Crashes

Document ID: KB-SW-002
Title: Application Crashes
Category: Software > Application Stability
Priority: Medium
Version: 1.0
Status: Active
Owner: IT Service Desk
Last Updated: 2026-09-15

## Symptoms

- Application unexpectedly closes.
- Application freezes during use.
- User receives repeated application error messages.
- The issue occurs when performing a specific task.

## Possible Causes

1. Application bug.
2. Outdated application version.
3. Corrupted application files.
4. Insufficient system resources.
5. Incompatible plugin or extension.
6. Operating system compatibility issue.

## Prerequisites

- User should save work whenever possible.
- Support staff should record the application name and version.

## Troubleshooting Steps

1. Record the application name and error message.
2. Restart the application.
3. Restart the device if the problem continues.
4. Check for approved application updates.
5. Check available system resources.
6. Disable or remove unsupported extensions if applicable.
7. Reproduce the issue and record the steps that cause the crash.

## Resolution

The application operates without unexpected crashes.

## Escalation

Escalate to Software Support if:

- The application repeatedly crashes.
- A software defect is suspected.
- Multiple users experience the same problem.
- The issue requires vendor support.

## Security Notes

Do not install unofficial patches or modified versions of the application.
