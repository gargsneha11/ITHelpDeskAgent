# Software Update Failed

Document ID: KB-SW-003
Title: Software Update Failed
Category: Software > Updates
Priority: High
Version: 1.0
Status: Active
Owner: IT Service Desk
Last Updated: 2026-09-15

## Symptoms

- Application update fails.
- Update repeatedly downloads but does not install.
- User receives an update error.
- Application reports that it requires an update but cannot complete it.

## Possible Causes

1. Insufficient disk space.
2. Network connectivity problem.
3. Device restart is pending.
4. Previous update was incomplete.
5. Update service is unavailable.
6. Device does not meet update requirements.

## Prerequisites

- Device must be connected to an approved network.
- Updates should be performed using the organization's approved software-management system.
- User should save work before restarting.

## Troubleshooting Steps

1. Record the update error message.
2. Confirm network connectivity.
3. Check available disk space.
4. Restart the device.
5. Check whether another update is already in progress.
6. Retry the update through the approved software-management system.
7. Verify the installed application version.

## Resolution

The application is successfully updated to the approved version.

## Escalation

Escalate to Software/Desktop Support if:

- The update repeatedly fails.
- Multiple devices experience the same update failure.
- The update service appears unavailable.
- Manual administrative intervention is required.

## Security Notes

Do not bypass organizational update controls or download updates from unofficial sources.
