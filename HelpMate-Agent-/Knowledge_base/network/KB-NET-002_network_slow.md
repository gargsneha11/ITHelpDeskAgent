# Network Connection Is Slow

Document ID: KB-NET-002
Title: Network Connection Is Slow
Category: Network > Connectivity
Priority: Medium
Version: 1.0
Status: Active
Owner: Network Support
Last Updated: 2026-09-15

## Symptoms

- Websites and internal applications load slowly.
- File transfers take longer than expected.
- Video meetings experience buffering or poor quality.
- Network response times are unusually high.

## Possible Causes

1. Weak wireless signal.
2. Network congestion.
3. Local device resource usage.
4. Network service outage or degradation.
5. High bandwidth usage by another application.
6. Faulty network hardware.

## Prerequisites

- User must have an active network connection.
- Support staff should have access to approved network monitoring or diagnostic tools.

## Troubleshooting Steps

1. Confirm whether the issue affects one application or all network services.
2. Check whether the device is connected through Wi-Fi or a wired connection.
3. If using Wi-Fi, move closer to the approved access point.
4. Check whether other users are experiencing the same issue.
5. Test network latency using an approved diagnostic tool.
6. Check for active downloads, backups, or other high-bandwidth applications.
7. Retry the affected service.

## Resolution

Network performance returns to an acceptable level and affected applications operate normally.

## Escalation

Escalate to Network Support if:

- Multiple users are affected.
- Network latency remains high.
- A network outage or hardware problem is suspected.
- Performance problems occur across multiple locations.

## Security Notes

Do not install unauthorized network-monitoring software.
