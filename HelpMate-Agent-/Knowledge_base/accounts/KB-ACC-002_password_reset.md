# Password Reset

Document ID: KB-ACC-002
Title: Password Reset
Category: Accounts > Password
Priority: Medium
Version: 1.0
Status: Active
Owner: IT Service Desk
Last Updated: 2026-09-15

## Symptoms

- User cannot authenticate with their password.
- User reports that their password has expired.
- User has forgotten their password.

## Possible Causes

1. Incorrect password.
2. Expired password.
3. Password was recently changed.
4. Account synchronization delay.

## Prerequisites

- User identity must be verified according to organizational policy.
- User must have access to the organization's approved password-reset method.

## Troubleshooting Steps

1. Confirm the user account exists.
2. Check the account status.
3. Determine whether the password has expired.
4. Direct the user to the organization's approved password-reset process.
5. After the reset, allow time for account synchronization.
6. Ask the user to retry authentication.

## Resolution

The user can authenticate successfully using the newly established password.

## Escalation

Escalate to Identity and Access Support if authentication continues to fail after the password reset.

## Security Notes

- Never request the user's password.
- Never store passwords in tickets, logs, or knowledge articles.
- Do not provide passwords through email or chat.
